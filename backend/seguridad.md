# Seguridad web

La seguridad del backend protege los datos de los usuarios y evita que la aplicación sea atacada.

## Amenazas más comunes

- **Inyección SQL:** el atacante mete código SQL en un formulario para leer o borrar datos.
- **XSS (Cross-Site Scripting):** se inyecta JavaScript malicioso en una página que ven otros usuarios.
- **CSRF:** se engaña al usuario para que envíe una petición no deseada desde una sesión abierta.
- **Fuerza bruta:** probar muchas contraseñas hasta acertar.
