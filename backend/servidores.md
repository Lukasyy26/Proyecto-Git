# Servidores

Un servidor es un programa (o un equipo) que recibe peticiones de los clientes, normalmente navegadores, y devuelve una respuesta.

## Tipos de servidores

- **Servidor web:** sirve páginas y archivos estáticos (Apache, Nginx).
- **Servidor de aplicaciones:** ejecuta la lógica de negocio (Node.js, Flask, Django, Spring).
- **Servidor de bases de datos:** almacena y gestiona los datos (MySQL, PostgreSQL).

## Cómo funciona una petición

1. El usuario escribe una URL en el navegador.
2. El navegador envía una petición HTTP al servidor.
3. El servidor procesa la petición y consulta, si hace falta, la base de datos.
4. El servidor devuelve una respuesta (HTML, JSON, una imagen...).
