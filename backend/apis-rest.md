# APIs REST

Una API REST es una interfaz que permite que dos programas se comuniquen por HTTP, normalmente intercambiando datos en formato JSON.

## Principios de REST

- **Cliente-servidor:** el cliente y el servidor son independientes.
- **Sin estado:** cada petición lleva toda la información necesaria.
- **Recursos identificados por URL:** por ejemplo `/usuarios/5`.
- **Operaciones estándar** mediante los verbos HTTP.
